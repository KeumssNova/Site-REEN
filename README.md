# Reen AI (Site-REEN)

A web platform showcasing an Africa-focused AI Language Model (LLM), built with modern JavaScript stack.

---

## 🚀 Features

- **Interactive LLM interface**: Query the AI model directly from the browser.
- **Dynamic content integration**: Loads content such as contextual prompts, info panels tailored to African cultures.
- **Responsive design**: Works smoothly across mobile and desktop.

---

## 🧱 Tech Stack

| Layer       | Technology         |
|-------------|--------------------|
| Frontend    | React              |
| Backend     | Node.js + Express  |
| Database    | MongoDB            |
| Deployment  | Vercel/Heroku  |
| Others      | Axios, React Router, ... |
